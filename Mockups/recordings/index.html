Recording Guide

Recording a Session

Turn on Record This Session before Start Practice. Only beats that actually make sound are captured; recording does not change live conducting or firmware.

Recordings

Play or pause generated audio, export WAV, edit, or delete with confirmation. Select uses square checkboxes. Use # to start at a stored measure.

Touchpad Recording

The first New Measure Beat starts recording. You may provide a starting measure number; sound and measure number lock after recording starts.

Editor Timeline

● regular or measure start   ● accent   ● selected

Scroll beyond the last beat to add later beats. Tap a beat to edit it, hold and drag it to move it, or drag the red playback line to seek.

Edit Safely

Set exact time from 0–86400 seconds; Earlier/Later move 10 ms. Delete asks first. Revert restores original beats and sound but keeps the current name.
