Recording guide

Record a session

Enable Record this session, then use the same Start practice button. Only beats you hear are captured.

Manage recordings

Search by name, play generated audio, export WAV, edit, or delete. Select uses square checkboxes for batch deletion. The # button plays a numbered recording from a specific measure.

Touchpad measures

Optionally enter the first measure number before tapping. Regular beats inherit it and each later New measure beat counts upward.

Read the timeline

● Regular beat   ● Accent   ◉ New measure

Scroll vertically, including past the last beat, to add beats later in the recording.

Edit safely

Accent and Measure show their current On/Off state. Earlier/Later move 10 ms. Delete asks first and remains undoable before saving. Revert restores original beats and sound.
